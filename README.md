# 运行与修改指南 (Guide for Local Setup)

你好！如果在本地直接双击打开 `index.html`，页面会是一片空白。这是因为本作使用了 React 和 Vite 框架，现代浏览器的安全策略（CORS）不允许在 `file://` 协议下直接运行 JavaScript 模块代码。

要在你本地的电脑上查看和修改网站，请按照以下步骤操作：

## 1. 安装 Node.js
如果你还没有安装 Node.js，请前往 [Node.js 官网 (nodejs.org)](https://nodejs.org/) 下载并安装长期支持版 (LTS)。

## 2. 安装依赖并启动本地服务器
打开终端（Windows 上的 CMD/PowerShell，或 Mac 上的 Terminal 操作），使用 `cd` 命令进入到你下载解压后的网站文件夹目录（即包含 `package.json` 的目录）。

在终端中依次运行以下两行命令：
```sh
npm install
npm run dev
```

运行成功后，终端会显示类似如下的局域网地址：`http://localhost:3000` (或其他端口号)。用浏览器打开该地址，你就能看到网站了！此时修改代码，网页会自动热更新。

## 3. 关于图片/视频等素材的路径
Vite 项目规定，**静态素材必须放在 `/public` 文件夹下**。
你提到“文件中加入了素材但在浏览器没显示”，主要有两个原因：
1. 本地直接点开 `index.html` 导致代码没起作用。
2. 素材放置的位置不对。

**请在项目根目录（即跟 index.html 同级的位置）新建一个名为 `public` 的文件夹**，然后把你需要的图片和视频全部拖到 `public` 文件夹里。

目前代码里写的文件名是：
- `/0-cover 1.jpg`
- `/调色后.mov`
- `/A4 - 1.jpg`
- `/cookie.png`
- `/cover mockup.png`
- `/gif-museum.png`
- `/if cover横.png` (请注意，名字中“if cover”和“横.png”之间如果没有空格，请重命名素材文件使其完全匹配代码，或修改 src/i18n/translations.ts 里的代码来匹配素材名)
- `/logo.png`

在代码中，我们是用类似 `src="/A4 - 1.jpg"` 这样的路径引入的，只要你把这些文件放在 `public` 文件夹下，代码就能自动读到它们啦。

## 4. 如果你想在 AI Studio 网页上预览
目前我在 AI Studio 这里也是看不到你本地下载后加进去的素材的。如果你希望在这个页面的预览框里看到真实完整的画面，你需要在这里的左侧文件管理器里点击“上传”，把这些图片和视频传上来，或者将它们直接拖拽到工作区。

另外你可以暂时在本地愉快地修改它！如果你在代码上有什么需要我帮忙加的，也可以随时告诉我。
